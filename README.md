## Topics explored

Computer input, processing, output and storage; hardware and software; Terminal commands and safe file operations; operating systems, processes, permissions and paths; interpreted and compiled programs; binary, decimal, hexadecimal and UTF-8; version control, branches and Pull Requests; LAN/MAN/WAN, DNS, routers and client-server communication.

## Run the number converter

From this folder run `python3 mission-05-numbers-data/number_converter.py`. Enter a non-negative whole number when prompted.

## Learning summary

The computer accepts input, processes it with hardware and software, then presents and stores results. Operating systems manage resources and provide services to applications. Python can convert between number bases, and Git records project changes so they can be reviewed and shared. I learned that clear folder structure and small commits make a project easier to inspect. Binary, hexadecimal, Python conversions, DNS and Git each solve different parts of how computers represent data and share work.
